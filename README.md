# Mert Ömeroğlu — Portfolio

A bilingual software developer portfolio presenting selected products, experience, education, and technical capabilities.

**[Visit live website](https://mertomeroglu.com)**

## Highlights

- Turkish and English portfolio experience
- Selected software projects and professional background
- Downloadable CV presentation
- Responsive contact and profile navigation

## Verified technology

Next.js, React, TypeScript, Tailwind CSS, Framer Motion, Lenis, and jsPDF are confirmed in the private source manifest.
